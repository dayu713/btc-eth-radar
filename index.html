    口径、算法与可靠性说明
    00 / 日内方向：确定性启发式，不是预测

    必须有新鲜现价、完整当日1m（含 VWAP / CVD）、前收、前日冻结价值区、新鲜 ATR 与至少30分钟当日收盘成交历史；离线、核心读取失败、数据过期或换日立即“观望”。以最新完整5m边界为准，最近两根5m收盘均高于各自当时会话 VWAP、PDC、前日 VAH 且超出噪声带才算结构偏多；均低于各自 VWAP、PDC、前日 VAL 才算偏空。噪声带 max(0.2×ATR14/5m, 最近收盘×0.05%)；相关价格参考合为一个结构家族，不累加投票。资金流取同边界最近15根完整1m 的 Σ(2×主动买量−总量)/Σ总量，≥+5%偏买、≤−5%偏卖；只在结构和资金流同向时显示“看涨/看空”，冲突、模糊或弱流均“中性”。不是用全日 CVD 正负判趋势。加载已有历史可直接评估，无需等待第二次轮询；不足历史则预热。OI 仅在连续且时间匹配的价量快照中提示参与度，绝不单凭增仓看涨；资金费率只提示付费/潜在拥挤风险（每期绝对值≥0.03%为提示阈值），IV/ATR不投方向票。辅助数据缺失明确注明，不伪造。此标签无胜率、概率或预测承诺，不产生方向通知、不自动交易。

    新增 / 挂单墙仅辅助

    Binance公开500档 REST 深度随主刷新30–60秒采样，无额外快速循环。买卖侧分别以 BTC 5 USDT / ETH 0.25 USDT 固定桶聚合基础币数量与 USDT 名义规模；双重门槛为 BTC≥100万 / ETH≥50万 USDT 且≥同侧非空完整桶中位数的可调倍数（默认3倍）。远端不完整桶剔除、至少5桶才筛选。显示最近及主要价桶、深度价格覆盖、相对成交价/快照中价距离、同桶规模变化与最多20条事件。连续观察仅指本页相邻不同快照，非订单身份或真实存续时间；断档、过期、失败、换日即重置。未见价桶或规模下降不等于撤单，可能成交、撤改、移出500档窗口或基线变化；快速诱导挂单无法由稀疏快照识别。绝不参与看涨看空判断，也不发挂单墙通知。

    01 / 同一交易市场，同一日界

    价格、PDH / PDL、分钟成交、OI、资金费率全部来自 Binance USDⓈ-M 的 BTCUSDT / ETHUSDT 永续。不是现货，也不是 OKX。UTC 00:00 为日界，即北京时间 08:00；所有显示时间为北京时间（UTC+8）。PDH / PDL 取前一个完整 UTC 日的 1d K 线高低。今日统计只使用已收盘 1m K 线，未收线的一根不计。

    02 / POC、VAH、VAL 是分钟分布估算

    把每根 1m K 线的基础币成交量，按价格区间重叠比例均匀分配到固定价桶（BTC 25 USDT，ETH 1 USDT）。单价 K 线归入对应桶。最大成交量桶中心为 POC（同量取较低桶）。从 POC 逐次选相邻成交量更大的一侧扩张，直到覆盖至少 70% 总量（同量先向下）；VAL / VAH 为区域下 / 上边界。不是逐笔成交分布；桶宽、分钟内分配假设会影响结果，发展中价位会移动。

    03 / VWAP 与 CVD

    VWAP = 当前 UTC 会话已收盘分钟的 quote asset volume 总和 / base asset volume 总和；使用实际聚合成交额，不以典型价代替。CVD = Σ(2 × taker-buy base volume − base volume)，单位 BTC 或 ETH，折线从会话起点累计；是真实主动买卖量字段的聚合，不用 K 线涨跌猜方向。缺口时仅显示已获数据的小计，明确标注不完整并禁用价位提醒。

    04 / OI 与资金费率

    OI 来自 openInterest，单位为基础币 BTC / ETH，不是美元也不是合约张数。USDT 名义值为 OI × 同市场最新成交价的近似换算（USDT 不等同 USD）。箭头对比上次成功且未过期的同一资产读数，不代表净多空。资金费率为 premiumIndex.lastFundingRate 原值 × 100%，不是下次结算的保证值；正值通常多方付空方。周期优先 fundingInfo 的调整值，否则明确显示交易所标准 8 小时假设；下次时间取 nextFundingTime。变化为百分点。

    05 / 期权 IV：不是“每天的百分比”

    Deribit 币本位 BTC / ETH 期权独立于 Binance 永续。选择剩余 6 小时至 8 天中，最近一个存在可用双边报价、Call / Put 合计持仓大于零的到期日，再选最接近其自身期货标的价的相同行权价 Call / Put。显示两者 mark_iv 的简单平均，单位为年化 %；不是 25Δ IV，不是 DVOL，不保证是日到期期权。另列 IV / √365 作为一天隐含波动率换算（平方根时间假设），并非未来涨跌预测。差值仅比较相同到期、行权价、C/P 组合，换档重置。报价可用不等于深度充足。

    06 / 提醒：价格移动，不把价位移动当突破

    触及容差为价位的 0.01%（BTC 最低 0.10 / ETH 最低 0.01 USDT）。首次、换日、读取中断超过 180 秒仅建基线；穿越用相邻两次价格同时跨过新旧价位验证，触及须由容差外进入且价格确有移动。价位本身移动超过一个容差则重新建基线。触发后须先远离 3 倍容差再回来，并有每币每位 90 秒冷却；区间内停留不连发。30–60 秒轮询会漏掉两次读取之间的穿越，不是交易所触发单。关页 / 休眠后无监控；后台至少 60 秒且可能被浏览器节流，系统通知也受 macOS 权限控制。

    07 / 网络、分页与过期

    无需服务器、CDN、构建或 API Key；直接用浏览器的 CORS fetch（不带凭证）。首次今日与前日各最多每币 4 页 × 499 根分钟线顺序分页，另取 200 根已收盘 5m 预热 ATR；以后有重叠地增量拉取，缺口则下轮重拉。每条请求 10 秒超时，临时错误最多重试一次，限流退避；403 / 451 不尝试绕过地域限制。不支持的网络或本地文件策略会显示错误，保留的旧读数会标为过期，不会填造行情。价格超过 120 秒、OI / IV 超过 180 秒、资金费率超过 180 秒、分钟线尾落后超过 150 秒会标记。页面会独立检查服务器时间与本机时钟。

    补充 / 冻结参考、波动带与压力区

    PDC 为前日收盘。前日 POC / VAH / VAL 使用完整 1440 根前日 1m，独立冻结，不用今日发展中分布替代。ATR14 由最近 200 根已收盘 5m 的真实波幅做 Wilder 平滑，初始 14 个 TR 为算术均值；有限历史预热与交易终端可能略有差异。VWAP 标准差使用每分钟成交额/量的均价按量加权，忽略分钟内离散，是近似而非逐笔标准差。上方聚类只合并价格距离在容差内的已有价位，最多显示最近 6 区；分布、VWAP、前日 OHLC 各视为一类，不为相关价位重复加权。不是可靠性排序、触碰胜率或卖出信号，不编码“第4次一定突破”等经验断言。

    08 / 强平估算的边界

    用户指定线性近似：多 E×(1−1/L+MMR)，空 E×(1+1/L−MMR)。另给简化逐仓权益关系：多 E×(1−1/L)/(1−MMR)，空 E×(1+1/L)/(1+MMR)。两者均不等于交易所精确强平：忽略手续费、资金费、风险档位、维持保证金速算扣除、额外保证金、全仓抵押、标记价与成交价差异。MMR ≥ 1/L 时提示保证金约束冲突，不能把结果当作可开仓价格。
